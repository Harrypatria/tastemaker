# Narratives, Archetypes and Copy

## Structures

| Deck | Structure |
|---|---|
| Investor pitch | Hook, Problem, Solution, Product, Market, Traction, Business model, Competition (by type), Team, Ask |
| Strategy / QBR | Executive summary, Results vs targets, Drivers, Risks, Decisions needed, Plan, Appendix |
| Board update | Headline, KPIs vs plan, What changed, Risks and mitigations, Asks of the board |
| Product launch | Why now, What, Demo flow, Proof, Pricing and availability, Next steps |
| Sales | Pain, Cost of inaction, Solution, Proof (case), Implementation, Pricing, CTA |
| Training | Objective, Concept, Example, Practice, Recap, Resources |
| Status update | TL;DR, Done, Next, Blockers, Asks |
| Research readout | Question, Method, Key findings (one per slide), Implications, Recommendations |

## Slide archetypes

| Archetype | Use | Structure |
|---|---|---|
| Title | opener | title, subtitle, presenter, date, logo |
| Statement | key claim | one sentence at 56-72px, optional support line |
| Big number | KPI | number 120-160px, label, delta with icon, context line |
| Chart + takeaway | evidence | chart at 60-70% width, 2-3 callouts or an annotation |
| Comparison | options | 2-3 columns with identical rows, recommendation highlighted |
| Process / timeline | steps, roadmap | max 6 nodes |
| Matrix | prioritisation | 2x2 with labelled axes and plotted items |
| Table | detail | max 6 rows x 5 columns, key cell highlighted |
| Quote | proof | real, attributed, permitted only |
| Image + text | story | 50/50 or 60/40 split |
| Agenda / divider | orientation | numbered sections, current highlighted |
| Closing | ask | one action, owner, date, contact |

## Copy

- PAS for problem slides, BAB for transformation, AIDA across short sales decks, 4U for titles.
- Title = verb + result + number when data exists.
- Replace adjectives with evidence ("fast" -> "p95 220ms").
- Parallel structure in lists; sentence case; no emoji; no hype (C01).
- Data gaps go to speaker notes as "DATA NEEDED", never as fake numbers on the slide.
