# Voice and Messaging

## Personality sliders (place 1-5, record a reason)

Formal - Casual · Serious - Playful · Authoritative - Humble · Technical - Plain · Reserved - Enthusiastic · Traditional - Innovative

## Voice principles

Three, in the form **"We are X, so we Y, but never Z."** e.g. "We are direct, so we lead with the answer, but never dismiss a concern."

## Tone matrix (voice constant, tone adapts)

| Context | Tone | Shape | Example |
|---|---|---|---|
| Onboarding | warm, encouraging | short, active | "Connect your bank to see this month's cash flow." |
| Success | brief, affirming | 1 sentence + next step | "Invoice sent. We'll remind Dana on 14 May." |
| Error | calm, accountable | cause + fix | "We couldn't reach your bank. Try again in a minute, or upload a CSV." |
| Billing / legal | precise, neutral | complete sentences | no cleverness, no abbreviations |
| Marketing hero | confident, concrete | 6-12 word headline | benefit + audience + mechanism |
| Empty state | helpful, light | 2 short lines + action | "No invoices yet. Create one or import from CSV." |
| Destructive confirm | serious, specific | name target + consequence | "Delete 'Q3 forecast'? Charts using it will stop updating." |

## Microcopy

Buttons verb + object, never "Submit"/"OK" for meaningful actions. Avoid "simply", "just", "easy", "oops", "please note", and blame ("you entered an invalid..."). Sentence case. Exclamation marks only for real milestones. Numerals with units and locale formatting.

## Banned hype list (C01)

unlock, supercharge, elevate, seamless, revolutionize, effortless, cutting-edge, game-changer, next-level, unleash, empower, world-class, best-in-class, state-of-the-art, robust, synergy, "harness the power", "in today's fast-paced world", "take X to the next level", "look no further".

Replace with the outcome, the number and the mechanism: "Reconcile 2,000 transactions in 4 minutes with rules you write once."

## Messaging framework

| Layer | Content | Length |
|---|---|---|
| Tagline | the promise, original | 3-7 words |
| Value proposition | outcome + audience + differentiator | 1 sentence |
| Elevator pitch | problem, solution, proof | 30 words |
| Pillars (3) | benefit headline + 2 proof points | 1 line + 2 bullets |
| Boilerplate | about paragraph | 50 words |
| Audience messages | pain, benefit, objection answer per segment | table |

Formulas: **PAS** (problem, agitate, solve), **AIDA**, **BAB** (before, after, bridge), **4U** headline test (useful, urgent, unique, ultra-specific), **FAB** (feature, advantage, benefit).

## Consistency audit

| Check | Pass condition |
|---|---|
| Color | guideline colors only; contrast pairs met |
| Type | defined families, scale, weights only |
| Voice | matches principles; no banned words; sentence case |
| Logo | clear space, min size, approved lockup, undistorted |
| Imagery | matches style rules; no stock clichés |
| Copy | competitor test passed; verbs on buttons |
| Accessibility | contrast, alt text, reading level about grade 8 |
